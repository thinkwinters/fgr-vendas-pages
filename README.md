# fgr-vendas-pages

Landing page premium (mobile-first) do empreendimento **Jardins Berlim | FGR**, construída em HTML + CSS + JS puro.

## Arquivos principais
- `index.html`: estrutura da página + copy inicial.
- `style.css`: estilos premium, responsivos e acessíveis.
- `script.js`: menu mobile, validação dos formulários e lightbox da galeria.

## Edição rápida
### Textos e copy
Edite diretamente as seções dentro de `index.html` (cada bloco está comentado por seção).

### Link de WhatsApp
Substitua `https://wa.me/5500000000000` por seu número oficial (formato internacional sem símbolos) em `index.html`.

### Formulários
Os formulários atualmente fazem validação front-end e exibem mensagem de sucesso local em `script.js`.
Para integração real (CRM, webhook, etc.), altere o evento `submit` em `script.js`.

### Imagens (placeholders)
Troque os caminhos abaixo por imagens finais mantendo os mesmos nomes, ou ajuste no `index.html`:
- `/images/berlim-hero.jpg`
- `/images/berlim-lazer.jpg`
- `/images/berlim-portaria.jpg`
- `/images/berlim-casa.jpg`
- `/images/berlim-piscina.jpg`

### Mapa
Na seção de localização, o bloco `.map-placeholder` em `index.html` pode ser substituído por embed do Google Maps ou imagem estática.
